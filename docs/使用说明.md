# LumiCurve 工作台 · 使用说明

## 一、怎么打开

| 方式 | 操作 |
|---|---|
| **桌面快捷方式** | 双击桌面上的 **LumiCurve 工作台** |
| 文件夹里 | 双击 `打开应用.bat` |
| 命令行 | `python app/server.py`（会自动开浏览器） |

**当前版本是本地网页版**（v0.4）：启动后起一个本地服务（127.0.0.1:8770），
用系统默认浏览器打开界面。左边是参数，右边实时预览，改任何控件约 0.3 秒后自动重画。

为什么改成网页版：定稿的新拟物风格依赖**双向软阴影 / 内阴影 / 渐变弧线**，
这些是 CSS 的原生能力；tkinter 连圆角都没有，做出来只能是个打折的仿制品。
旧的 tkinter 版本 `lumi_workbench.pyw` 仍保留，作为不能用浏览器时的备选。

> 界面里如果看到旧样式，按 Ctrl+F5 强制刷新（静态资源带了版本号，
> 正常情况下不会缓存）。

## 二、两个页面

### 1. 配色材质（CMF 方案卡）

做一张产品配色提案板：主产品效果图 + 材质色卡 + 色号 + 色觉检查 + 配色变体。

| 参数 | 说明 |
|---|---|
| 产品名称 | 显示在卡片标题 |
| 配色方案 | 类似色 / 互补色 / 三分色 / 分裂互补 / 单色渐变 |
| 材质 | 哑光陶瓷 / 磨砂 / 金属拉丝 / 皮革 / 高光塑料（全部程序生成，不依赖贴图） |
| 器型 | 造型瓶 / 台式灯 / 便携音箱 |
| 主色相 | 0–359°，色轮角度 |
| 配色数量 | 2–5 色 |
| 饱和度 / 明度 | 控制整组色的浓淡 |
| 色觉关怀 | 勾上后自动把明度拉开（见第四节） |
| 可辨识阈值 | 两色 ΔE00 低于这个值就算"容易混"，默认 12 |

出品：**保存方案卡到 out/** 存 PNG（1600×1300）。

### 2. 灯具配光

模拟灯罩把灯泡的光打在地面上的效果，看照度分布、衰减曲线。

| 参数 | 说明 |
|---|---|
| 罩口半径 / 灯罩高度 / 收腰系数 | 决定灯罩母线形状 |
| 光通量 | 灯泡总流明 |
| 内壁反射率 | 罩内壁镜面反射比例 |
| 离桌距离 | 罩口到桌面 |
| 目标半径 | 想照亮的范围，用来算均匀度 |

预览会同时给出**俯视照度分布**（等照度圈）和**沿半径衰减曲线**。
保存时额外输出一张**轴截面光线追迹图**和原始数据 CSV。

## 三、色名和色号是怎么来的

这一步是重点，因为"名字和颜色对不上"是最常见的翻车点。

1. 先把颜色**吸附**到色库里真实存在的颜色上。
   色库 = 常用色名（100 色）+ 中国传统色（526 色），共 627 色，
   传统色那部分带原始 CMYK 值。
2. 吸附的判定用 **CIEDE2000 色差**（不是简单的 RGB 距离，RGB 距离在蓝色区会严重失真），
   同时限制色相偏移和明度偏移，避免"为了迁就名字把颜色改得面目全非"。
3. 色名优先取**常用色名**；同名冲突时自动换下一个最近且不重名的。
4. 所以卡片上每个色块旁边的名字，指的就是那块颜色本身，不会出现"浅蓝叫群青"。

每个色卡下面给出完整色号：

```
#5C9DCC      HEX
RGB 92 157 204
CMYK 62 26 8 0
L* 62        明度
```

> 顺带标注一个"传统色"名（如「霁青」），方案书里写起来好看，且两者色差在 ΔE00 6 以内。

## 四、色觉关怀

色弱用户（红绿色盲约占男性 8%）看色卡时，几块颜色可能完全是同一个灰。

**检查**：卡片中部的 COLOUR VISION SUPPORT 一栏，把整组色分别用
Machado(2009) 的红色型 / 绿色型 / 蓝黄色盲模型跑一遍，逐对算 ΔE00：

- `ΔE ≥ 阈值` 绿色显示，可区分
- `ΔE < 阈值` 橙色显示，并在下面点出是哪两块、差多少

**修复**：勾上「色觉关怀」，程序会把整组颜色的明度按等间距重排
（色相家族和彩度都不动，提亮最多 +12、压暗最多 −34，防止冲成惨白或发灰），
重排时仍然落到色库里的真实颜色上，所以色名照样精确。

另外每个色块都印了 01–05 编号，色块之间不靠颜色也能对上号。

## 五、命令行（交作业要 CLI 的话）

```bat
python cmf_card.py --hue 205 --n 4 --scheme analogous --material matte --shape bottle ^
                   --name "曲水 · 陶瓷香薰器" --out out/card.png --cvd-fix

python lamp_curve.py --mouth 0.115 --height 0.26 --power 800 --dist 0.6 --target 0.5 ^
                     --out out/case1.png --save-ray
```

`cmf_card.py` 会给每个颜色打印色名、HEX、RGB、CMYK、L*，以及四种视觉条件下的最小色差。

## 八、方案卡版式主题（v0.4 新增）

方案卡有两套版式，用 `--theme` 切换：

`at
python cmf_card.py --theme dark  ...   :: 深色海报版（默认）
python cmf_card.py --theme light ...   :: 浅色纸张版
`

浅色版把底、墨色、分隔线、通过/警告色全部换成纸张配色，
并在版式里加了三到四道**同心破形弧线**（圆心在色卡中下部，向上散开，
穿过页眉横线和分区线），和界面左侧色相盘发散的弧是同一套语言。

色块、色觉行、主色小方块在浅色版下都带一圈浅灰发丝描边，
避免浅色色块在纸白底上"露边"。

## 九、v0.5 新增（第一轮：交互与预设）

### 1. 点色卡切换主色
方案卡上的**每个色块、每个变体小瓶、左侧主色方块**都可以点。
点一下，左边色相盘和饱和度/明度会跳到那个颜色，整组配色按当前方案重算。
悬停会高亮并显示色号。

### 2. 拼色预设（15 组）
左侧「拼色预设」一栏，横向 15 个色条 + 一个「自动」：
青花瓷 / 汝窑天青 / 莫兰迪 / 敦煌土红 / 青绿山水 / 海盐蓝 / 麦田黄 /
赤陶 / 石墨灰 / 抹茶 / 紫藤 / 薄荷奶 / 蜜桃 / 落日橘 / 孟菲斯

- 选中预设后，色相盘和滑轨自动置灰（不再参与生成），配色**严格按预设值**
- 预设生效时会**自动关掉色觉重排**，保住设计师原本给的配色；
  想看病弱友好版，手动把「色觉关怀」拨开即可
- 在方案卡上点任意色块，会自动退回「自动」模式

预设定义在 `presets.json`，加一组只要往数组里补一行。

### 3. 器型扩充到 10 个
花瓶 / 造型瓶 / 香水瓶 / 香薰瓶 / 醒酒器 / 收纳罐 / 直筒杯 / 台式灯 / 球泡灯 / 便携音箱

器型就是一组母线控制点（Catmull-Rom 插值后绕轴旋转），
在 `cmf_card.py` 的 `SHAPES` 里加数据即可，不用改渲染代码。

一览图见 `out/器型一览.png`。

## 十、v0.6：Bug 修复 + 无障碍增强

### 修掉的三个问题
1. **新增器型全被退回默认** —— `server.py` 里的器型白名单是写死的三个，
   新器型判为非法自动退回。改成 `list(MC.SHAPES.keys())`，以后加器型不用再改两处。
2. **拼色预设不好切换** —— 预设条左右各加一个 ‹ › 箭头，点一下换一组，
   选中项会自动滚动到可见位置。
3. **用了预设后下面的调试台失效** —— 原来是把色相盘和滑轨直接锁定，
   现在改成：**预设只是起点**，一旦你动色相盘或任何滑轨，自动退回「自动」模式继续调。

### 无障碍增强（三件）
1. **色弱视图**（顶栏按钮）—— 不再只是模拟色块，而是**把整组配色做成的产品本身**
   按四种视觉各画一遍：正常 / 红色型 / 绿色型 / 蓝黄型。
   哪两块在色弱眼里糊成一块，一眼就能看出来。示例见 `out/色弱模拟示例.png`。
2. **WCAG 对比度** —— 状态栏给出"相邻色最小对比度"和"产品对台座的对比度"，
   对照 WCAG 非文本内容 3:1 的建议值。
3. **找达标方案** —— 一键搜索：先在当前配色方案里微调色相/饱和/明度，
   不达标再尝试三分色/分裂互补；候选按**真实渲染流程（含色觉明度重排）**复核。
   会明确告诉你改了什么，或者老实说"这组颜色本身太接近，还是不行"。
   实测耗时约 3.5 秒。

## 十一、v0.7：真 3D 产品预览（第二轮开始）

顶栏多了 **「3D 视图」** 按钮。打开后，右侧不再是方案卡，而是**可以转的 3D 产品**：

- 一组配色的 4 个色号会**并排立体展示**，鼠标拖动转视角、滚轮缩放
- 器型来自同一套母线数据（`cmf_card.SHAPES`），由 `LatheGeometry` 旋转 96 等分生成
- 材质按当前选择映射到 PBR 参数（哑光/磨砂/金属/皮革/高光 各自不同的 roughness 与 metalness）
- 光照是三点光 + 程序生成的环境贴图（不用外部素材），地面接触阴影也是程序画的

技术说明：
- three.js r160 已**下载到本地** `app/web/vendor/`，不依赖网络
- 新增接口 `/api/geo`：只算几何与配色、不渲染卡片，所以调参数时 3D 立刻响应
- 方案卡与 3D 是两条并行路径：卡是"提案板"（静态、可打印），3D 是"看产品"（可转）

示例图：`out/3D视图示例.png`

## 十三、v0.9：壁厚 / 木纹 / 光源

### 1. 模型加壁厚（实体壳）
之前是 LatheGeometry 直接旋转母线，得到的是**一张无限薄的曲面**——不像产品，也没法 3D 打印。

现在把母线扩成一条**闭合环线**：底面圆心 → 外底面 → 外壁向上 → 口沿 → 内壁向下 → 内底面。
壁厚取归一化 0.020（约合 300mm 高的器物 6mm），所以：
- 瓶口是**开口**，能看到内壁和口沿厚度
- 网格是封闭实体，后续导出 STL 直接可用
- 相机稍微抬高，能看进口沿

### 2. 木纹材质
Poly Haven `ash_veneer`（白蜡木皮，CC0）。处理上有三个坑：
1. **木纹是横的** → 旋转 90° 让纹理立起来，跟器物轴线平行
2. **木皮太平，法线几乎是空的** → 从亮度场重新生成法线，补上细微起伏
3. **albedo 被我压得太狠** → 用分位数拉伸把对比度还原到 0.60~1.00

同时打通了方案卡那侧：`cmf_card.py` 加了程序化木纹场（纵向纹路 + 年轮），
`server.py` 的材质白名单改成跟着 `MAT_CN` 自动同步（**这是今天第三次踩同一个坑**：
器型、材质都因为写死白名单而静默退回默认值）。

### 3. 光源档位
顶栏「光源」按钮循环四套打光：**工作室 / 侧逆光 / 顶部光 / 柔光箱**。
每次切换，主光位置上会浮现一颗**半透明光源球**，1.5 秒后淡出——让你看见光从哪来。

示例图：`out/3D_木纹与壁厚.png`

## 十四、v1.0：STL 导出 + 可打印性检查（老师那条"直出产品"）

### 用法
左侧面板底部多了一块「3D 打印」：**打印高度**（120~400mm）、**壁厚**（1.5~8mm）。
顶栏 **「导出 STL」** 一键导出，同时状态栏给出打印检查报告。

### 报告内容
外形尺寸 / 壁厚 / 体积 / PLA 耗材估算 / 三角面数 / 最大悬垂角（>45° 提示需支撑）/ 是否封闭。

### 几何实现
- 母线沿法向等距偏移得到内壁，合成闭合环线（底面 → 外壁 → 口沿 → 内壁 → 内底）
- 绕轴旋转成网格，**Z 轴朝上、底面 z=0**（切片软件约定）
- 二进制 STL，法线由叉积计算

### 踩到的两个真问题
1. **半径没按毫米缩放**——母线是归一化的（高度 1），一开始只缩放了 Z，结果模型是 0.5mm 粗。
2. **轴心不是流形**——轴心那圈生成了 96 个位置重合但拓扑独立的顶点，
   三角扇的边都只属于一个面。改成**轴心共用一个顶点**后，
   边流形检查从 384 条坏边降到 **0**。
   （这条本来我在报告里写死了"封闭 √"，实测才发现是假的，不能想当然。）

### 各器型的打印体检
| 器型 | 体积 | 耗材 | 最大悬垂 | 需支撑 |
|---|---|---|---|---|
| 花瓶 | 327cm³ | 405g | 39° | 否 |
| 直筒杯 | 285cm³ | 353g | 19° | 否 |
| 醒酒器 | 298cm³ | 370g | 39° | 否 |
| 香薰瓶 | 218cm³ | 270g | 40° | 否 |
| 造型瓶 | 356cm³ | 441g | 51° | 是 |
| 香水瓶 | 315cm³ | 390g | 48° | 是 |
| 收纳罐 | 410cm³ | 508g | 59° | 是 |
| 便携音箱 | 575cm³ | 713g | 58° | 是 |
| 球泡灯 | 221cm³ | 274g | 87° | 是（球面悬空） |
| 台式灯 | 290cm³ | 360g | 84° | 是（灯罩外扩） |

样例文件：`out/样例_花瓶_300mm_3mm壁.stl`

## 十五、v1.1：修两个反馈问题

### 1. 音箱是空心的 → 器型分两类
之前**所有器型都按"开口容器"处理**，于是音箱、球泡灯的顶部也开了个口，露出内壁。

现在按本质分两类（`printing.CLOSED_SHAPES`）：
| 类型 | 器型 | 处理 |
|---|---|---|
| 开口容器 | 花瓶 / 造型瓶 / 香水瓶 / 香薰瓶 / 醒酒器 / 收纳罐 / 直筒杯 / 台式灯 | 外壁 + 内壁 + **口沿**（能看到厚度） |
| 封闭壳体 | 便携音箱 / 球泡灯 | 外壁 + 内壁，**顶部封口**（外形闭合，内部仍有空腔） |

注意：**封闭外形 ≠ 实心块**。我第一版直接做成实心，音箱体积算出来 8011cm³（9.9 公斤耗材），
明显不对；改成封闭壳体后是 610cm³（756g），正常。

### 2. 打印参数不影响模型 → 已贯通
之前 3D 视图里壁厚是**写死的** `0.020`，两个滑轨根本没被读取。现在：
- `/api/geo` 会带上 `wall`（= 壁厚mm / 外形mm，归一化）和 `closed` 标记
- 3D 视图按这个壁厚重建网格，所以拖滑轨能立刻看到口沿变厚/变薄
- 状态栏同步显示「开口容器 / 封闭壳体 · 壁厚 Xmm / 外形 Ymm」

顺带说明：**外形高度不影响屏幕上模型的大小**（模型按比例显示），
但会影响"壁厚相对比例"——同样 3mm 壁，120mm 的小件看起来就比 400mm 的大件厚。

## 十六、花纹（纹样）系统 · v1.2

### 16.1 能做什么

- **所有 10 种器型**都能加花纹：花瓶 / 造型瓶 / 香水瓶 / 香薰瓶 / 醒酒器 / 收纳罐 / 直筒杯 / 台式灯 / 球泡灯 / 便携音箱。
- 7 种纹样：**无花纹 / 回纹 / 莲瓣 / 水波 / 缠枝 / 竖条纹 / 波点**。
- **花纹颜色直接取自色卡**：左侧「花纹色」下拉里列出的就是当前配色的 01–04 号色，
  默认取 02 号；纹样颜色不是另调一个新颜色，而是配色方案里真实存在的那一支。

### 16.2 怎么用

1. 左侧「花 纹」一行：左边选纹样，右边选花纹色。
2. 3D 视图下改花纹立刻重绘；方案卡（关掉 3D）也会同步把花纹画到产品上。
3. 页脚会标注「纹样：回纹（花纹色 色04）」，保存的方案卡与色号 txt 里都会记录。

### 16.3 实现要点（讲作业时可用）

- 器型都是回转体，UV 天然是「绕一圈 × 沿母线」，所以纹样只要画一张 512×512 的
  **遮罩图**，就能包裹任意器型，不需要给每个模型单独建模纹路。
- **位置按物理高度锚定**：母线 UV 的 v 并不按高度均匀分布（细颈会吃掉大半 v），
  所以 rebuild() 里把顶点 v 直接重写成「离底面的高度比例」，
  纹样锚点用 0(底)~1(口) 的物理高度描述，换器型也不会跑到口沿上去。
- **花纹色与材质分离**：材质贴图转成灰度只提供质感细节，主体色与花纹色在
  画布上合成成一张 albedo，所以「哑光陶瓷 / 木纹 / 皮革 + 回纹」都能正确叠色。
- **圆点按口径比修正**：横向 UV 是整圈周长、纵向是高度，直接画圆会被拉成扁椭圆，
  因此按 1/(2πr̄) 压缩圆点的横向半径，在宽体（音箱）上才是圆的。
- 纹样全部程序生成，无外部素材，可离线运行。

### 16.4 已知限制

- 花纹目前是「颜色层」，没有浮雕厚度；要做成立体纹（浮雕/丝网印刷质感）需要
  在 STL 里挤出，属于下一步。
- 同一个方案里花纹色只能选一支色，暂不支持双色纹样。

## 十七、浮雕立体纹 · v1.3

之前的花纹只是"颜色层"（贴图），这一次把它做成**真的隆起**：几何里挤出厚度，
导出的 STL 拿去切片就能打出带浮雕的实物。

### 17.1 怎么用

1. 先选一个花纹（「花纹」不能是"无花纹"）。
2. 「3D 打印」区里出现「浮雕深度」滑杆（0–1.2 mm，默认 0.6 mm）；选"无花纹"时这一行会变灰。
3. 3D 视图里立刻能看出来；**滚轮放大**看边缘高光最清楚。
4. 「导出 STL」导出的就是带浮雕的实体，文件名会带上 `_meander0.8mm` 这样的标记。

### 17.2 三个地方看到的是同一件事

| 位置 | 做法 |
|---|---|
| 3D 视图 | 外壁顶点沿半径方向外推，位移量按花纹高度场逐点采样；周向自动加密到 256 等分，并重算法线 |
| 方案卡 | 按高度场梯度修正法线，所以卡片上的纹样有真实的凸起高光与阴影 |
| STL | 同一套高度场写进网格，外壁全分辨率、内壁抽稀，导出的实体水密 |

### 17.3 实现要点（讲作业时可用）

- **遮罩 → 高度场**：花纹遮罩先做 2.8px 高斯模糊再用。二值直接挤出会得到一刀切的台阶
  （切片时是峭壁、边缘还容易糊），模糊后是斜坡，才算浮雕。
- **只推外壁**：环线 (r, y) 里前 N 点是外壁，只有它们加偏移；内壁、底面、口沿都不动，
  拓扑完全不变，所以水密性天然保持。
- **面数控制**：浮雕需要分辨率，周向从 96 提到 256 等分、母线全保留 240 点，
  但内壁按 1/4 抽稀（看不见的部分不该占三角面）。最终 17 万面 / 8.3 MB。
- **法线必须重算**：只挪顶点不算法线，光照是平的，看上去"没变化"。

### 17.4 实测数据（花瓶 300mm 高，壁厚 3mm，回纹 0.8mm）

| 指标 | 无浮雕 | 有浮雕 |
|---|---|---|
| 三角面 | 46,464 | 173,952 |
| STL 体积 | 2.22 MB | 8.29 MB |
| 体积 | 326.8 cm³ | 336.1 cm³ |
| PLA 耗材 | 405 g | 417 g |
| 水密 / 坏边 | 水密 / 0 | 水密 / 0 |

独立复核（把导出的 STL 读回来重新查）：17 万面、水密、260,928 条边全部恰好共用两次；
纹样带那一圈的半径起伏实测 **0.79 mm**，带外那一圈 **0.00 mm** —— 浮雕只在纹样处。

### 17.5 打印建议与限制

- 浮雕深度 **0.4 mm 起**才明显；0.6–0.8 mm 最好看；1.2 mm 已经偏"厚重"。
- 切片层高建议 **0.12–0.16 mm**：0.28 mm 的粗层高会把 0.6 mm 的浮雕层次吃掉一半。
- 浮雕做在接近垂直的外壁上，**不增加悬垂**，不需要额外支撑（报告的悬垂角不变）。
- 目前是"整片纹样同高度"的浮雕，还没有做多层叠雕（比如回纹套莲瓣的高低两层），
  也没有做凹雕（往里压）——这两个是下一步。

## 十八、画笔手绘花纹 · v1.4

程序纹样再好也是"别人的图案"。这一版可以直接**在器物上画**，画出来的东西
跟着花纹色一起出方案卡、一起进 STL、一起有浮雕。

### 18.1 怎么用

1. 顶栏点「画笔」→ 自动切到 3D 视图，并把花纹设成「手绘」。
2. 在器物上**按住左键画**；右键拖动转视角，滚轮缩放。
3. 底部悬浮工具条：**橡皮**（再点一次退出橡皮）、**笔刷**大小 4–48、**清空**、**完成**。
4. 画完点「完成」，随时可以切回方案卡看效果。
5. 花纹颜色还是走左边的「花纹色」，默认自动取与主色对比最大的那一支。

### 18.2 实现要点

- 笔迹存在一张 512×512 的 **UV 遮罩画布**上（横向绕一圈、纵向从口到底），
  和程序纹样共用同一条管线：调色 → 贴图 → 浮雕高度场 → STL。
- **射线拾取**：鼠标位置 → 相机射线 → 与器物求交，直接拿到交点的 `uv`，
  所以画在哪就落在哪，不用先展开再对着平面画。
- **跨接缝**：画到接缝（u=0/1）时把笔迹同时画在 −512 / 0 / +512 三个位置，
  环绕不断线；相邻两点的 u 会先"解卷绕"，避免横穿整圈拉出一条长线。
- 落笔时只重画被点到的那只器的贴图（约 3–5 ms），**抬笔才重算几何**（浮雕要重挤），
  所以画的时候不卡。
- **遮罩上传**：浏览器画完把画布导成 PNG，POST 到 `/api/mask` 换一个短 token，
  之后的 `/api/cmf`、`/api/print`、`/api/stl` 都用 `mask=<token>` 引用它，
  不用把几十 KB 塞进 URL。
- 三个渲染器的环绕角已统一（以 three.js 的 φ 为准，正面 u=0）：
  3D 视图、方案卡、STL 的浮雕位置一一对应。

### 18.3 实测

- 手绘波浪 + 浮雕 0.6mm，花瓶 300mm：173,952 面、8.29 MB、水密 / 坏边 0、
  体积 332.1 cm³（素坯 326.8）、耗材 412 g。
- 独立复核导出的 STL：水密；花纹那一圈的半径起伏 1.01 mm，素面处 0.00 mm。

### 18.4 限制

- 手绘只存在**当前会话**里：关掉应用就没了（遮罩在浏览器内存 + 服务端内存）。
  需要长期保存的话，下一步可以存成 PNG 一起进 out/。
- 只支持**单支画笔**：没有对称、撤销、笔压。画错了用橡皮或「清空」。
- 画在正面最直观；转到背面画也行，但内侧（通过瓶口看见的那面）也会一起有花纹，
  因为内外壁共用同一套 UV。

### 18.5 撤销（v1.4.1）

- 工具条左边第一个按钮就是**撤销**，按钮上带数字表示还能退几步（最多 14 步）。
- 快捷键 **Ctrl + Z**，画笔模式下随时可用。
- **一笔 = 一步**：按下左键的那一刻存一张快照，抬笔算一笔。所以画歪了一笔，
  按一下撤销就整笔消失，不用拿橡皮一点点蹭。
- 「清空」也会记一步，清空了也能撤回来。
- 撤销后贴图、浮雕、方案卡、STL 全部跟着回退（和落笔走的是同一条链路）。

### 18.6 锁住视角（v1.4.1）

- 工具条里的**锁定**按钮：点上之后相机彻底不动——不转、不缩放，
  画的时候器物就定在那儿，笔迹不会跟着跑偏。
- 再点一次解锁，就可以右键转视角 / 滚轮缩放。
- 按钮变琥珀色表示"已锁定"，状态栏也会说明。

顺带修掉一个真问题：以前**每抬一次笔，视角就会被自动掰回默认机位**
（每笔结束都要重建几何，重建时又顺手调了一次取景），所以画两笔就得重新找角度。
现在取景只在"器的数量 / 器型 / 画布比例"真的变化时才重算，你转到的角度会一直保留。

### 18.7 重做 · 调色盘 · 笔刷粗细（v1.4.2）

工具条现在是两行：

```
[撤销 N] [重做 N]  ● ● ● ●
[● —— 笔刷 —— 24]  [橡皮] [清空] [锁定] [完成]
```

**重做**
- 撤销旁边就是「重做 N」，撤销多了就点它回到下一步。
- 快捷键：**Ctrl+Z** 撤销、**Ctrl+Shift+Z** 或 **Ctrl+Y** 重做。
- 一旦你又画了新的一笔，"重做"会清空（和所有画图软件一致）。

**调色盘**
- 第一行那四个圆点就是**当前配色的四支色**（跟着左边色卡走，不是另开一套颜色）。
- 点哪个用哪个画；换了颜色之后**新笔迹用新颜色，旧笔迹保持原色**——
  所以一个瓶子上可以同时有紫色浪花 + 青色横纹。
- 调色盘和左边「花纹色」下拉是联动的：改一边，另一边跟着变。
- 方案卡按**笔迹自己的颜色**上色（不是整片单色），后端会把遮罩按 RGBA 解析。

**笔刷粗细**
- 滑块范围放宽到 **2–96**（掩膜像素），滑杆左边的实心圆点是当前笔头大小预览。
- 键盘 **`[`** 变细、**`]`** 变粗，一次 2 像素。
- 橡皮和画笔共用同一个粗细，颜色各自独立（擦完接着用原来的颜色）。

> 小提示：笔迹落在 512×512 的环绕展开图上，所以瓶子越细的地方（比如瓶颈）
> 同样的笔刷看起来越窄——这是真实的展开关系，不是笔刷失灵。

### 18.8 完整色板：赤橙黄绿青蓝紫 × 各明度（v1.4.3）

工具条里点「**色板**」弹出完整调色板：

- **60 个色块 = 12 个色相 × 5 档明度**
  - 色相：赤 / 橙 / 橙黄 / 黄 / 黄绿 / 绿 / 青绿 / 青 / 天青 / 蓝 / 蓝紫 / 紫
  - 明度：上排最浅（L*≈88）→ 下排最深（L*≈37），每档都取**该色相在这一明度下
    能到的最大彩度**（再往上就会超出 sRGB 被削平变灰），所以每格都是同类里最鲜艳的那支
- 弹层顶部还有一行「**方案色**」：当前 CMF 配色的 4 支色，点它就是把它用作画笔色，
  和左边「花纹色」下拉联动——方案色用于方案，色板用于手感
- 顶部显示当前画笔色的十六进制值
- 选中的色块会有蓝色描边；关掉弹层点外面空白处即可

**为什么明度排成一行一行**
色相生成用的是 OKLCH（感知均匀的色彩空间），同一行的 L 值相同，
所以横着看是"同一个明度下的不同色相"，竖着看是"同一个色相的不同明暗"，
比直接调 HSV 的明度要均匀得多（HSV 的黄和蓝在同一个 V 值下看起来完全不一样亮）。

> 手绘笔迹是**彩色**的：先选红画一道、再选绿画一道，瓶子上就是两道不同颜色的纹。
> 方案卡、STL 浮雕都会跟着来（STL 只有形状，颜色不进网格）。
